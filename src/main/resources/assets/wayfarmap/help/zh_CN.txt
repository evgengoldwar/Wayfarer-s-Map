# {icon:chunkload} 区域加载（/wf chunkload）
该命令无需走遍即可绘制§f你周围的大片区域§r：服务器会加载（必要时生成）区块，地图会将它们绘制出来。

- §e/wf chunkload 2d <半径>§r — 平面地图，半径以区块为单位
- §e/wf chunkload 3d <半径>§r — 平面地图和 3D 地图（较慢）
- §e/wf chunkload status§r — 查看进度
- §e/wf chunkload stop§r — 停止
- §e/wf regionload 2d|3d <半径>§r — 仅加载世界中已保存的区块，不生成任何内容；用 §efull§r 代替半径 — 加载该维度的所有区域文件

§f从地图操作：§r§b模式 → 区域加载§r（仅限管理员）会显示仅§a在 2D 地图上§r的区块（绿色）、仅§9在 3D 地图上§r的区块（蓝色）、§d两者都有§r的区块（紫色）、§7已保存在世界中§r但尚未绘制的区块（灰色）以及§c排队中§r的区块（红色）。工具栏右下角的箭头可隐藏或显示图例下方的鼠标按键提示。
- §eCtrl+鼠标左键拖动§r — 从区域文件按原样加载矩形内的灰色区块（不生成任何内容）
- §eShift+鼠标左键拖动§r — 生成矩形内的区块（包括从未生成过的区块）
- §eCtrl+Shift+鼠标左键拖动§r — 生成区块并包含所有洞穴层
- §eCtrl+鼠标右键拖动§r — 立即从地图§c删除§r该矩形（同时移出队列）。你周围已加载的区块会立即重新绘制
- §eShift+鼠标右键拖动§r — 取消：将矩形内排队中（红色）的区块移出队列
- §b从区域文件加载全部§r — 立即加载此维度中保存的所有区块（会先确认；不生成任何内容）
- §b删除维度地图§r — 删除此维度的整张地图（会先确认；路径点保留）
- 开启§b设置 → 3D 地图 → 记录方块§r时，以上所有操作也会对 3D 地图生效

- 世界地图底部会显示进度：已完成的区块数和§f已耗时秒数§r
- 离开世界或前往其他维度 — 加载会暂停，回来后继续
- 速度 — §b设置 → 命令§r

! 需要管理员权限（单人游戏中需允许作弊）。在共享服务器上，较大的半径会增加服务器负载。
